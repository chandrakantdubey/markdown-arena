# Using the Markdown Arena

The **Arena Editor** is your sandbox for experimentation.

## Why use the Editor?
- **Real-time Preview**: See exactly how your syntax renders as you type.
- **Debug Syntax**: If a table isn't rendering, paste it here to check if the syntax is valid GFM.
- **Diagramming**: Test complex Mermaid diagrams before adding them to your documentation.

## Features
1. **Split Pane**: Code on the left, rendered HTML on the right.
2. **HTML Support**: Unlike standard GitHub READMEs, we allow raw HTML execution for learning purposes (Script tags are still sanitized/discouraged).
3. **Syntax Highlighting**: The editor helps you spot unclosed tags or formatting errors.
