# Markdown Cheat Sheet

| Element | Syntax |
| :--- | :--- |
| **H1** | `# Heading 1` |
| **H2** | `## Heading 2` |
| **Bold** | `**Bold**` |
| **Italic** | `*Italic*` |
| **Link** | `[Text](URL)` |
| **Image** | `![Alt](URL)` |
| **List (Ordered)** | `1. Item` |
| **List (Unordered)** | `- Item` |
| **Code Inline** | ` ` (`backticks`) |
| **Code Block** | ```` ``` ```` |
| **Blockquote** | `> Quote` |
| **Table** | `| Col | Col |` <br> `| --- | --- |` |
| **Task** | `- [x] Task` |
| **Strikethrough** | `~~Strike~~` |
| **Break** | `---` |
