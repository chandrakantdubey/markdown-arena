# Platforms & Portability

Markdown renders differently depending on where you paste it.

## GitHub
- Uses **GitHub Flavored Markdown (GFM)**.
- auto-links issues and PRs (`#123`).
- Supports syntax highlighting for hundreds of languages.
- Blocks explicit style tags (`<style>`) and scripts.

## Discord
- Supports a subset of Markdown.
- **Bold**, *Italic*, `__Underline__`, `~~Strikethrough~~`.
- Code blocks with standard syntax highlighting.
- Support for spoiler tags `||spoiler||`.
- **No** headings, lists or images (via markdown syntax).

## Slack
- Historically inconsistent, now moved towards standard markdown.
- Supports `*` for bold, `_` for italic.
- `>` for blockquotes.
- Code blocks.

## Reddit
- Uses a variant called "snoomarkdown" (based on GFM).
- Supports superscript `^text` and spoilers `>!spoiler!<`.
