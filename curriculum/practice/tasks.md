# Record release readiness

Make Build complete and Review pending. Mark the obsolete archive name as struck through and put the new filename in a code span.

## Starter

~~~~markdown
Build the archive
Review the checksum

bundle.tgz is now release.tgz.
~~~~

## Hint

Task markers belong after the list marker, with a space on either side of the bracketed marker.

## Worked solution

~~~~markdown
- [x] Build the archive
- [ ] Review the checksum

~~bundle.tgz~~ is now `release.tgz`.
~~~~

## Self-check

Two checkboxes appear, with only Build checked. Changing the space to x marks Review complete in the preview.
