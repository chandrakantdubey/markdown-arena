# Give a release note an outline

Turn the title into a level-one heading, the two major sections into level-two headings and the checksum section into a subsection of Install. Keep the prose as paragraphs.

## Starter

~~~~markdown
Field guide

Install
Download the archive.

Verify the checksum
Compare the two values.

Remove
Delete the unpacked directory.
~~~~

## Hint

Count the hashes before each heading.

## Worked solution

~~~~markdown
# Field guide

## Install

Download the archive.

### Verify the checksum

Compare the two values.

## Remove

Delete the unpacked directory.
~~~~

## Self-check

The outline has two siblings, Install and Remove. Verify the checksum sits inside Install. Removing the space after a hash makes that line ordinary text.
