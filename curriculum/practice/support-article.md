# Write a support troubleshooting article

A learner says their edited lesson has disappeared after switching devices. Drafts live in browser storage, and resetting the page can remove the saved work. Write a symptom-led article. Start with checks that preserve the learner’s remaining copy. Make the distinction between refreshing a page and resetting a draft explicit.

## Starter

~~~~markdown
# My draft is missing

Try resetting.
~~~~

## Hint

Translate a complaint into an observable symptom. Put any action that could discard evidence after preservation steps.

## Worked solution

~~~~markdown
# Find a missing lesson draft

## First check

Open the same lesson or exercise in the original browser profile on the original device. Each document has its own draft. Copy any visible work into a local file before changing browser settings.

## What do you see?

| Observation | Next action |
| --- | --- |
| Draft appears on the original device | Copy it to move it to the second device |
| A different exercise is open | Return to the original topic using Browse course |
| Browser storage was cleared | Look for a previously exported or copied version |

Refreshing reloads the page and its saved draft. **Reset draft** replaces that draft with the lesson starter. Use reset only when you intend to discard your edits.
~~~~

## Self-check

A reader with a surviving draft can recover it without an irreversible first step. A reader with cleared storage gets a realistic next action.
