# Repair a nested procedure

Build three ordered steps. Put the README and checksum inside step two as bullets. Give step three a second paragraph that stays inside that item.

## Starter

~~~~markdown
Download the archive
Inspect the contents
README
Checksum
Unpack the archive
Keep a backup.
~~~~

## Hint

Align continuation content with the first letter after the ordered marker.

## Worked solution

~~~~markdown
1. Download the archive
2. Inspect the contents
   - README
   - Checksum
3. Unpack the archive

   Keep a backup.
~~~~

## Self-check

The outer list counts to three. Both files sit under the second step and the backup instruction aligns with the text of the third step.
