# Build a GitHub profile README

Introduce yourself to a future collaborator. Use the profile form or edit the source. Name the problem you work on, link one project, and explain what a reader should look for there. Choose a professional or friendly introduction, include your focus, skills, collaboration interests and relevant links. Copy or download the result as README.md. Publish it in a public repository named exactly like your GitHub username, with README.md at its root. Check the profile page after committing.

## Starter

~~~~markdown
# My name

What I work on

## Featured project

Project link and contribution

## Currently learning

One specific topic
~~~~

## Hint

Start with a verb and a reader. Use a real link and describe whether you built, contributed to, or learned from the project.

## Worked solution

~~~~markdown
# Mira Shah

I write small tools that make release notes easier to review.

## Featured project

[Markdown Arena](https://github.com/chandrakantdubey/markdown-arena) is a course I am learning from. Open its practice directory to see how a starter and a worked answer fit together.

## Currently learning

How to explain a chart when the image is unavailable.
~~~~

## Self-check

Read the exported README as a stranger. Can you identify the author’s focus, follow a working link and find evidence for the description? Try the preview with images disabled. The profile publication steps are in the Use cases chapter. Keep achievements verifiable, use descriptive links, avoid excessive badges, and remove placeholders before publishing. Third-party statistics widgets are optional and may fail or expose viewer network metadata.
